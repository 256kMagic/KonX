# KonX 0.16.1 — Recognizable update filenames

2026-10-22. Replace the generic `payload.exe` staging name with a KonX filename containing the version being installed.

## Fix

- Stage installed updates as `KonX-Setup-<version>.exe` and portable updates as `KonX-<version>-portable.exe`, matching the public release filenames. Windows prompts that display the installer filename can identify KonX and the target version.
- Validate the version before creating update files and independently validate the expected filename inside the helper's own handoff directory. Keep size and SHA-256 verification before installation, cancellation, cleanup, and portable recovery.
- Preserve the installed folder, portable launcher filename, and existing profile. Cisco highlighting and earlier features remain available.

## Upgrade

Use **Update KonX** from installed 0.6.2 or later or portable 0.6.0 or later. Installed 0.6.0/0.6.1 and version 0.5.0 or earlier require a manual upgrade; see [Updating KonX](../UPDATING.md).

**An update started by 0.16.0 or an older copy can still display `payload.exe` while installing this fix.** The running older updater chooses that name. Updates started from 0.16.1 use the new versioned name. To use the versioned filename immediately, download and run the [0.16.1 installer](https://github.com/256kMagic/KonX/releases/download/v0.16.1/KonX-Setup-0.16.1.exe) manually.

Windows x64 downloads: [installer](https://github.com/256kMagic/KonX/releases/download/v0.16.1/KonX-Setup-0.16.1.exe), [portable](https://github.com/256kMagic/KonX/releases/download/v0.16.1/KonX-0.16.1-portable.exe), and [checksums](https://github.com/256kMagic/KonX/releases/download/v0.16.1/SHA256SUMS.txt). Executables remain unsigned; this change does not add a verified publisher identity.

## Validation

- **810/810 automated tests passed**, including 20 updater installation checks. Real Windows helper launches verify the branded installed/portable paths, actual installer invocation, cancellation, checksum rejection, cleanup, parent-exit handling, and portable recovery.
- Reject malformed versions before staging or starting a helper. Independently reject altered versions, modes, and paths in the real helper without executing the target or deleting files it does not own.
- **115 packaged source files** and **nine runtime dependencies** match the built application. **28/28 packaged SSH compatibility checks** and **16/16 private-key test groups** passed. Installer, portable, and application executable versions were verified.
- Both unpacked and portable applications passed two-launch checks with isolated profiles, including saved preferences, login retention, console logging, Cisco colors, and the existing tools.

Checks ran on Windows x64 with Node.js 24.13.0 and Electron 44.9.0. The user's installed application and profile were not changed.

## Coverage

Automated update checks use isolated files, profiles, local executable fixtures, and temporary test registrations. A real Windows elevation prompt and an elevated upgrade of the user's installation are not verified for this release. The limitations listed in [0.16.0](0.16.0.md#coverage), [SSH compatibility](../SSH_COMPATIBILITY.md), and [0.6.3](0.6.3.md#known-issues) remain unchanged.
