# KonX 0.23.0 — Contextual Copilot

2026-10-23. Keep troubleshooting conversations beside the source tool and review the complete request before sending it.

## Changes

- Open Copilot in the Workbench companion pane or as a floating/pop-out panel using existing window controls.
- Save local conversations, select immutable evidence and completed history, and retain exact requests and original sources with each answer.
- Preview the exact provider destination and JSON body, including knowledge excerpts. Enforce revision, expiry, and single-use review before sending.
- Test a configured connection only after explicit review; show actual provider usage and preserve cancelled, failed, or interrupted outcomes without automatic retries.
- Attach typed observations from nine basic network tools with original inputs, selected rows, times, and omission notices.

Read the [Copilot guide](../KONX_AI.md), [AI & Knowledge](../AI_KNOWLEDGE_GUIDE.md), and [user guide](../USER_GUIDE.md).

## Downloads and upgrading

Windows x64: [installer](https://github.com/256kMagic/KonX/releases/download/v0.23.0/KonX-Setup-0.23.0.exe), [portable](https://github.com/256kMagic/KonX/releases/download/v0.23.0/KonX-0.23.0-portable.exe), and [checksums](https://github.com/256kMagic/KonX/releases/download/v0.23.0/SHA256SUMS.txt).

Installed 0.6.2+ and portable 0.6.0+ can use **Update KonX**. Installed 0.6.0/0.6.1 requires one manual upgrade. Save drafts, stop listeners, and disconnect before restarting; the existing profile remains in use.
