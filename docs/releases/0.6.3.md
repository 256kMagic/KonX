# KonX 0.6.3 — October 21, 2026

KonX 0.6.3 is a version-only release carrying the same application and updater source as 0.6.2. It provides a newer public release for testing the full installed update workflow, including download, installation, restart, and settings preservation. It introduces no additional application features or updater fixes.

The installed updater fixes were introduced in [0.6.2](0.6.2.md): physical application-archive detection and validation of the installation's paired Windows registry keys. Those fixes remain included in 0.6.3.

## How to upgrade

| Current copy | Action |
| --- | --- |
| Installed 0.6.2 | Choose **Update KonX** on Home or under **Settings → Updates**. Finish any listed work, then approve Windows elevation if requested. |
| Installed 0.6.0 or 0.6.1 | Save work, close KonX, and run `KonX-Setup-0.6.3.exe` manually using the existing installation folder and per-user/all-users mode. These older buttons cannot install their own fix. |
| Portable 0.6.0 through 0.6.2 | Choose **Update KonX**, or replace the portable executable manually after closing KonX. |
| Version 0.5.0 or earlier | Close KonX and run the installer, or replace the portable executable manually. |

Do not uninstall the existing copy or delete its profile to upgrade. Installed updates preserve the installation folder and mode; portable updates retain the executable filename and location. Both continue using the existing Windows profile. Save local and remote files, Knowledge notes, and capture evidence before restarting; terminal connections and capture buffers are not restored.

The Windows x64 release includes [KonX-Setup-0.6.3.exe](https://github.com/256kMagic/KonX/releases/download/v0.6.3/KonX-Setup-0.6.3.exe), [KonX-0.6.3-portable.exe](https://github.com/256kMagic/KonX/releases/download/v0.6.3/KonX-0.6.3-portable.exe), downloadable guides, these release notes, and [SHA256SUMS.txt](https://github.com/256kMagic/KonX/releases/download/v0.6.3/SHA256SUMS.txt). For a manual download, compare `Get-FileHash .\KonX-Setup-0.6.3.exe -Algorithm SHA256` with the manifest. Checksums establish consistency with the GitHub release; the executables remain unsigned.

See [Updating KonX](../UPDATING.md) and the [user guide](../USER_GUIDE.md) for instructions, cancellation, and recovery.

## Existing features

Animated themes, SSH/SFTP, Notepad, packet reassembly, readable HTTP, SIP ladders and call export, Security Suite, Wi-Fi/Mist tools, and AI & Knowledge are unchanged from 0.6.2.

## Known issues

The six findings recorded in the [0.6.2 release notes](0.6.2.md#known-issues) remain unfixed: AI chunk-boundary credential redaction, relevant-passage omission during Knowledge retrieval, weak WPA/TKIP and group-cipher omissions, HSTS directive parsing, and interpretation of unapplied Cisco macro bodies. Verify affected assessments against the original evidence. Do not put sensitive credentials in custom Knowledge notes or rely on redaction to make them safe for AI requests. AI and Mist tests use simulated provider responses; they do not establish live-account interoperability.

## Validation

The full 0.6.3 test suite passed **485/485** on its final run. The first run passed 484/485 with one AI integration failure; that test passed independently and the subsequent full suite passed without code changes. The initial failure's cause remains undetermined.

The Windows x64 installer and portable executable built successfully. All 81 packaged source files are byte-identical to the source in the installed 0.6.2 release; required runtime dependencies and x64 native bindings are present. Isolated unpacked and portable 0.6.3 startup/restart checks passed, including synthetic encrypted credential persistence/removal and custom Knowledge note persistence/removal.

Before preparing 0.6.3, the published 0.6.2 installer was manually installed and its installed **Update KonX** button successfully checked the public release. The existing settings remained byte-for-byte unchanged. This confirmed installed recognition and a public update check; it did not yet exercise downloading and installing a newer release through that button.

The preceding 0.6.2 release passed 485 automated tests, packaged source/dependency verification, and isolated startup/restart checks. Earlier corrected source components also completed a real all-users installation handoff to the published 0.6.1 installer. These are prior validation results, not a completed installed 0.6.2 → 0.6.3 test.

The complete installed 0.6.2 → 0.6.3 UI update, restart, and settings comparison can be tested only after 0.6.3 is published. No successful outcome for that test is claimed here.
