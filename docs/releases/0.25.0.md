# KonX 0.25.0 — Traffic Copilot

2026-10-23. KonX adds packet, readable stream, SIP/RTP, capture comparison, security and wireless evidence to Copilot.

## Changes

- Attach a selected decoded packet, an already analyzed readable stream, a SIP call with SDP, or an RTP quality report from its existing analysis view.
- Explain selected capture-comparison changes, retained remote-capture reports, security findings, Wi-Fi observations and Mist entities.
- Preserve frame references, original collection scope, coverage and omissions. Attaching performs no new capture, parsing, account query, audio export or file read.

Read the [Copilot guide](../COPILOT.md) and [user guide](../USER_GUIDE.md).

## Downloads and upgrading

Windows x64: [installer](https://github.com/256kMagic/KonX/releases/download/v0.25.0/KonX-Setup-0.25.0.exe), [portable](https://github.com/256kMagic/KonX/releases/download/v0.25.0/KonX-0.25.0-portable.exe), and [checksums](https://github.com/256kMagic/KonX/releases/download/v0.25.0/SHA256SUMS.txt).

Installed 0.6.2+ and portable 0.6.0+ can use **Update KonX**. Installed 0.6.0/0.6.1 requires one manual upgrade. Save drafts, stop listeners, and disconnect before restarting; the existing profile remains in use.
