# KonX 0.8.0 — Device snapshots and change checks

Save named device snapshots before and after maintenance, then compare interface, VLAN, neighbor, route, and configuration observations with their original evidence.

## Features

- Named, immutable snapshots in the local profile, with history, report reopening, and explicit removal.
- Optional configuration and route collection from connected Cisco IOS/IOS-XE sessions. Ordinary Device Inspector collection keeps its existing scope.
- Before/after comparisons with category filters, source evidence, device matching, and explicit unverified coverage when output is incomplete.
- A synthetic demo comparison for trying the complete workflow without equipment.
- Raw command and configuration transcripts stay out of snapshot AI context.

See [Device snapshots](../DEVICE_SNAPSHOTS.md), [Device Inspector](../DEVICE_INSPECTOR.md), and the [phased roadmap](../ROADMAP.md).

## Upgrade

Use **Update KonX** from installed 0.6.2 or later or portable 0.6.0 or later. The current installation and profile are retained. Older installed copies need a manual upgrade; see [Updating KonX](../UPDATING.md).

Windows x64 downloads: [installer](https://github.com/256kMagic/KonX/releases/download/v0.8.0/KonX-Setup-0.8.0.exe), [portable](https://github.com/256kMagic/KonX/releases/download/v0.8.0/KonX-0.8.0-portable.exe), and [checksums](https://github.com/256kMagic/KonX/releases/download/v0.8.0/SHA256SUMS.txt). Executables remain unsigned.

## Coverage

Snapshots preserve observations, not a restorable device image. Configuration comparison does not simulate routing or apply rollback. Original running configurations can contain sensitive values and are stored as ordinary local files. Incomplete or ambiguous evidence remains unverified.

The six inherited AI, Wi-Fi, and security-assessment findings listed in [0.6.3](0.6.3.md#known-issues) remain unchanged.
