# KonX 0.7.0 — Device Inspector

Device Inspector brings Cisco IOS/IOS-XE operational observations into searchable tables and correlates IP/MAC addresses with observed switch ports. Open **Network Tools → Device Inspector** and choose **Load demo** to explore without equipment or network traffic.

## Features

- Collect version, interfaces, interface status, VLANs, MAC and ARP tables, CDP/LLDP neighbors, and PoE from selected connected SSH terminals.
- Use a separate diagnostic channel; terminal input stays separate. Stop a collection without closing the existing terminal.
- Inspect source commands and line references, with visible unsupported commands, timeouts, paginated or truncated output, and parser limitations.
- Search an IPv4 address or MAC across a report. Trace paths retain ambiguity, missing peers, and candidate endpoint ports.
- Export JSON reports and reopen them offline. Open the original terminal directly from a device or trace result.

See the [Device Inspector guide](../DEVICE_INSPECTOR.md), [user guide](../USER_GUIDE.md), and [roadmap](../ROADMAP.md). Saved snapshot history and before/after comparisons belong to the next phase.

## Validation

All **518 automated tests passed**, including 19 new analysis/trace checks, 13 collection checks, and a real Electron workflow covering demo loading, source navigation, JSON round trips, escaped remote text, cancellation, AI-context transcript exclusion, and window layouts at 900×560 and 1400×880.

A real loopback SSH server verified that collection uses only the diagnostic channel and leaves the terminal usable. Fault cases exercised paging, command denial, partial output, transport loss, timeouts, output limits, malformed UTF-8, and late channel callbacks.

Windows x64 installer and portable builds completed. All 85 packaged source files and eight runtime dependencies were verified. Isolated unpacked and portable startup/restart checks passed, including the packaged two-switch demo, endpoint trace, synthetic encrypted credential persistence/removal, and Knowledge note persistence/removal. Visual inspection passed at both tested window sizes.

Real Cisco hardware and credentials have not been supplied; local SSH fixtures and synthetic command output do not establish live-device interoperability. The installed production profile was not changed for these tests.

## Coverage and known issues

Collection targets common Cisco IOS/IOS-XE output formats using already connected SSH sessions. It does not discover or log into switches automatically, escalate privilege, collect per-VRF tables, or support all vendor/OS layouts. A MAC-table edge candidate does not prove physical attachment. Capture times and incomplete coverage remain visible.

The six inherited AI, Wi-Fi and security-assessment findings documented in [0.6.3](0.6.3.md#known-issues) are unchanged. This feature does not resolve those findings. Original device transcripts are excluded from the Device Inspector AI context; review any shared context before sending it.
