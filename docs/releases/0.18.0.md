# KonX 0.18.0 — Movable panels and pop-out windows

2026-10-22. Arrange existing terminals and tools inside KonX or across separate desktop windows while keeping their live state.

## Features

- Right-click an open tab to **Float in workspace** or **Pop out to window**. Floating panels support header dragging, edge/corner resizing, maximize/restore, and docking.
- Pop-outs are native resizable windows you can move to another monitor. **Dock back** or the Windows X returns the same panel to KonX. **Close tab** remains a separate action.
- Resize existing split layouts, drag tabs into panes or reorder them, and use **Reset workspace** to return panels to their default arrangement.
- Retain terminal connections and scrollback, editor text/models/undo, capture packets/filters, and existing tool results. Themes, menus, dialogs, and input follow the panel's window.
- Save geometry without restoring live sessions or launching jobs on restart. Keep pending child-window cleanup owned through quit and update handoff.

See the [workspace guide](../WORKSPACE_LAYOUTS.md) for controls, persistence, and close behavior.

## Upgrade

Choose **Update KonX** in installed 0.6.2 or later or portable 0.6.0 or later. Earlier installed versions require a manual upgrade; see [Updating KonX](../UPDATING.md).

## Coverage

Native-window checks use isolated profiles and owned loopback terminal connections. Automated checks do not establish compatibility with every multi-monitor/DPI arrangement, physical serial adapter, or remote device. Terminal selections may clear during resize/reflow; scrollback remains available. Pop-outs belong to the main application and do not survive exiting KonX.

Executables remain unsigned. A real elevation prompt and elevated installed upgrade are not verified for this release. Earlier [serial](../SERIAL_AUTO_BAUD.md), [SSH](../SSH_COMPATIBILITY.md), and [0.16.0 coverage limits](0.16.0.md#coverage) remain applicable.
