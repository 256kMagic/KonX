# KonX 0.14.0 — Workspace layouts

Choose the physical arrangement of KonX independently of its application theme.

## Features

- Add Workbench, Incident Desk, Operations Wall, and Focus Workspace to Appearance alongside the existing Classic layout.
- Preview each layout's structure in Settings; save the preference or cancel without applying it.
- Reuse existing session and tool instances while changing visible pane placement.
- Keep the focused command target distinct from other visible panes, with explicit focus and expand controls.
- Preserve application themes, terminal palette overrides, reduced motion, drafts, captured data, and normal close/update safeguards.
- Keep background connection events from stealing keyboard focus and retain all toolbar controls in smaller windows.

See the [workspace layout guide](../WORKSPACE_LAYOUTS.md) and [user guide](../USER_GUIDE.md).

## Upgrade

Use **Update KonX** from installed 0.6.2 or later or portable 0.6.0 or later. Older installed copies need a manual upgrade; see [Updating KonX](../UPDATING.md).

Windows x64 downloads: [installer](https://github.com/256kMagic/KonX/releases/download/v0.14.0/KonX-Setup-0.14.0.exe), [portable](https://github.com/256kMagic/KonX/releases/download/v0.14.0/KonX-0.14.0-portable.exe), and [checksums](https://github.com/256kMagic/KonX/releases/download/v0.14.0/SHA256SUMS.txt). Executables remain unsigned.

## Validation

- All 734 automated tests passed, including layout assignment/focus regressions and existing packet, SIP/RTP, device, runbook, theme, and updater workflows.
- The real Electron layout workflow passed across five layouts and eight application themes. Two real loopback SSH sessions verified focused command targeting and explicit broadcast; loaded packets, a dirty Monaco document, a runbook draft, and pending incident capture bytes survived layout changes. No incident was implicitly saved.
- Settings Save/Cancel, unknown-layout fallback, pane expansion, close guards, narrow context controls, and saved layout/theme/palette restoration passed. Appearance and all five layouts were visually reviewed at 900×560 and 1400×880.
- Packaged verification matched all 111 source files and eight runtime dependencies. Both unpacked and portable builds passed isolated-profile restart checks, including saved layout and encrypted synthetic AI/Mist settings. Executable versions match 0.14.0; signatures remain absent.
- Replaced the test-only SSH key generator after reproducing malformed keys from its Ed25519 serializer. The shared native RSA/PKCS1 fixture passed key-identity and real SSH workflows; production key handling and dependencies are unchanged.

An updater cancellation test returned a terminal failure in the first suite run. It passed 20 focused repetitions and both subsequent full runs; the original cause remains unconfirmed. Its assertion now includes the terminal reason for future diagnosis. No updater behavior or deadline was changed for this release.

## Coverage

Layouts organize open work; they do not introduce fleet monitoring, automatic evidence membership, live collaboration, or automatic reconnection on restart. Packet/SIP/RTP interpretation and tool-specific limits are unchanged.

Automated checks use isolated profiles, synthetic captures and local SSH peers. Production network equipment and a complete installed upgrade with Windows elevation remain unverified for this release. The user's installed copy and profile were not changed by release validation.

The six inherited AI, Wi-Fi, and security-assessment findings listed in [0.6.3](0.6.3.md#known-issues) remain unchanged.
