# KonX 0.16.0 — Cisco terminal colors

2026-10-22. Automatically highlight Cisco errors, interface states, and IP addresses without changing the terminal's original output.

## Features

- Show recognized Cisco errors and down states in red, up states in green, warnings in amber, and valid IPv4/IPv6 addresses in blue.
- Use the **Cisco colors** switch above each console to change that tab immediately. Save the global default under **Settings → Appearance → Output highlighting**, or a session override under **Terminal & Log**.
- Enable Cisco highlighting by default for profiles without a preference. Keep terminal palettes and application themes independently selectable, with readable highlight colors on light and dark backgrounds.
- Preserve remote ANSI colors, clipboard text, scrollback exports, and log content. Apply highlighting to interpreted terminal cells, including fragmented and wrapped output, rather than rewriting the incoming stream.
- Follow scrolling, resizing, and screen rewrites with bounded display work. Leave alternate-screen applications to manage their own colors.

See the [Cisco highlighting guide](../CISCO_HIGHLIGHTING.md) for supported patterns and controls. The quick login-saving and console logging features from 0.15 remain available.

## Upgrade

Use **Update KonX** from installed 0.6.2 through 0.15.2 or portable 0.6.0 through 0.15.2. Installed 0.6.0/0.6.1 and version 0.5.0 or earlier require a manual upgrade; see [Updating KonX](../UPDATING.md).

## Validation

- **808/808 automated tests passed.** Seven new parser/controller checks use the installed xterm buffer and decoration APIs; a two-process Electron workflow verifies the actual painted text, controls, and saved preferences.
- Verified fragmented UTF-8 and IP tokens, wrapped lines, Unicode cell widths, cursor rewrites, scrolling, resize/reflow, alternate screens, remote foreground/background colors, and dark/light highlight contrast. Buffer text, attributes, cursor state, copied text, and plain-text logs remain unchanged.
- Verified bounded viewport work with a 2,000-line scrollback, decoration reuse and cleanup, oversized wrapped records, and unusually large combining-character cells.
- **28/28 packaged SSH compatibility checks** and **16/16 private-key test groups** passed. **115 packaged source files**, **nine runtime dependencies**, the SSH patch, and executable version metadata were verified.
- Both unpacked and portable applications passed two-launch checks, including actual blue/green/red terminal glyphs, the live switch, unchanged copied/logged output, and a saved highlighting preference after restart. Existing quick-login retention, logging, layout, and tool checks also passed.

Two existing UI tests showed intermittent Windows viewport-resizing timeouts during an earlier run. Both passed four focused runs each and the final full suite. The test helper now includes display and geometry diagnostics on timeout; its tolerances remain unchanged.

Checks ran on Windows x64 with Node.js 24.13.0 and Electron 44.9.0. Installer and portable executables remain unsigned. The installed user's copy and profile were not changed.

## Coverage

Highlighting recognizes common output patterns; it is not a complete Cisco grammar or a device-health assessment. Unsupported text and unusually long wrapped lines may remain unhighlighted. Tests use synthetic Cisco text, local peers, and isolated profiles. Real Cisco hardware and an elevated installed upgrade remain unverified for this release.

The SSH runtime limits documented in [0.15.1](0.15.1.md) and the six inherited AI, Wi-Fi, and security-assessment findings listed in [0.6.3](0.6.3.md#known-issues) remain unchanged.
