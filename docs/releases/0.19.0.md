# KonX 0.19.0 — Saved Site Workspaces

2026-10-23. Save a site's working context and reopen it when needed.

## Changes

- Create and save named site workspaces with session groups, notes, capture-file references, incident links, and panel arrangements.
- Reopen supported panels without connecting, collecting, or reading referenced capture files automatically. Existing live tabs remain open; native pop-outs restore as floating panels.
- Preserve terminal/SFTP mode, split sizes, floating bounds, and selected layouts. Missing references stay visible for replacement.
- Duplicate, import, export, and delete workspace definitions. Structured credentials and inline connection specifications are rejected; literal notes and paths still require review before sharing.
- Protect newer revisions and unsaved drafts, publish local files atomically, and retain ownership of failed cleanup for retry.

Read [Saved Site Workspaces](../SITE_WORKSPACES.md), [Workspace layouts](../WORKSPACE_LAYOUTS.md), and [Updating KonX](../UPDATING.md).

## Downloads and upgrading

Windows x64: [installer](https://github.com/256kMagic/KonX/releases/download/v0.19.0/KonX-Setup-0.19.0.exe), [portable](https://github.com/256kMagic/KonX/releases/download/v0.19.0/KonX-0.19.0-portable.exe), and [checksums](https://github.com/256kMagic/KonX/releases/download/v0.19.0/SHA256SUMS.txt).

Installed 0.6.2+ and portable 0.6.0+ can use **Update KonX**. Installed 0.6.0/0.6.1 requires one manual upgrade. Save work and disconnect before restarting; the existing profile remains in use.

## Validation

- Full automated suite: **923/923 passed**, including workspace storage, real Electron editing and layout restoration, IPC file operations, revision conflicts, and shutdown cleanup.
- All **127 packaged source files** and 9 runtime dependencies matched the tested checkout; packaged SSH checks passed 28 negotiation cases and 16 key cases, and synthetic serial checks passed 27 cases.
- Unpacked and portable builds passed save/restart/reopen checks with isolated profiles. Site notes, groups, SFTP mode, existing preferences, and encrypted test credentials persisted; restoring references started no connections.
- Workspace UI inspected at 900- and 1280-pixel window widths. Installer, portable, and unpacked executable versions matched 0.19.0.

## Coverage

Tests use isolated profiles, synthetic records, and owned loopback peers. Real equipment, physical serial adapters, mixed-monitor behavior, and a real elevated installed upgrade remain unverified by this release. Executables remain unsigned. A workspace does not embed capture bytes, incident evidence, or saved credentials, and its reference IDs/paths can be unavailable on another computer.
