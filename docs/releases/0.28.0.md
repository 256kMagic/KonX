# KonX 0.28.0 — Header Updates and Terminal Clipboard Controls

2026-10-26. Updates are within reach from every workspace layout, with clearer terminal clipboard controls.

## Changes

- Move **Update KonX** from Home to the top-right header. **Settings → Updates** remains available, and updating still begins only when you choose it.
- Replace the right-click behavior dropdown with **Settings → Terminal → Paste clipboard on right-click**. Existing menu/paste preferences are preserved. New profiles leave it off to open the terminal menu; turn it on to paste. Text selection and multiline-paste confirmation remain available.
- Clarify **Automatically copy highlighted text** in Terminal settings. Existing saved preferences remain in effect; automatic copy is enabled by default for new profiles.
- Copy completed selections immediately, including when you quickly clear a highlight and paste. Clipboard read failures are shown, and a pending paste or multiline confirmation cannot send text into a replacement connection after reconnecting.

See the [terminal clipboard guide](../USER_GUIDE.md#copy-paste-search-and-links) and [update guide](../UPDATING.md).

## Downloads and upgrading

Windows x64: [installer](https://github.com/256kMagic/KonX/releases/download/v0.28.0/KonX-Setup-0.28.0.exe), [portable](https://github.com/256kMagic/KonX/releases/download/v0.28.0/KonX-0.28.0-portable.exe), and [checksums](https://github.com/256kMagic/KonX/releases/download/v0.28.0/SHA256SUMS.txt).

Installed 0.6.2+ and portable 0.6.0+ can use **Update KonX** from Home or Settings in the older version. Installed 0.6.0/0.6.1 requires one manual upgrade. Save drafts, stop listeners, and disconnect before restarting; the existing Windows profile remains in use.
