# KonX 0.24.0 � Workspace Copilot

2026-10-23. Choose terminal, file and editor evidence without leaving your work.

## Changes

- Add explicit terminal selection/viewport and connection diagnostics, including serial detection, logging and configured forwards.
- Add saved-session context, SFTP listing/selection/transfer metadata, and current editor selections or documents.
- Add the current-view evidence picker; attachments remain local, bounded and immutable, with no automatic commands, transfers or provider requests.

Read the [Copilot guide](../KONX_AI.md#workspace-evidence) and [user guide](../USER_GUIDE.md).

## Downloads and upgrading

Windows x64: [installer](https://github.com/256kMagic/KonX/releases/download/v0.24.0/KonX-Setup-0.24.0.exe), [portable](https://github.com/256kMagic/KonX/releases/download/v0.24.0/KonX-0.24.0-portable.exe), and [checksums](https://github.com/256kMagic/KonX/releases/download/v0.24.0/SHA256SUMS.txt).

Installed 0.6.2+ and portable 0.6.0+ can use **Update KonX**. Installed 0.6.0/0.6.1 requires one manual upgrade. Save drafts, stop listeners, and disconnect before restarting; the existing profile remains in use.

Answers display after complete redaction, even for streaming transports. Redaction recognizes configured credentials and known formats; arbitrary sensitive text still requires review.

An isolated unpacked smoke run hit Windows EPERM while atomically replacing a Change Validation record. The next run and the portable run passed. This and the earlier intermittent incident-manifest rename error remain under investigation; this release does not claim to fix them.
