# KonX 0.15.0 — Session management

Clear recent session history from Home and save a username and password together on the session editor's General page.

## Features

- Add **Clear recent sessions** to Home. Clear only recent history while retaining saved sessions, encrypted credentials, open connections, and other preferences.
- Keep Home's Quick connect entries while clearing history or returning to Home.
- Wrap Quick connect fields in narrow workspace panes instead of collapsing the Host field and overlapping its label with Port.
- Place Username, Password, and **Save password on this computer** together under **General → Login credentials**. New sessions enable saving by default when secure encryption is available.
- Retain an existing password when its field is blank; use **Remove saved password** to explicitly forget it. An unchecked Save option permits a one-time password with **Save & Connect**.
- Preserve the previous session and credentials when encryption or persistence fails, and keep the populated editor open for retry.
- Refresh the saved-session list after a save finishes following dialog closure, without starting a late connection.

See the [session management guide](../SESSION_MANAGEMENT.md) and [user guide](../USER_GUIDE.md).

## Upgrade

Use **Update KonX** from installed 0.6.2 or later or portable 0.6.0 or later. Older installed copies need a manual upgrade; see [Updating KonX](../UPDATING.md).
