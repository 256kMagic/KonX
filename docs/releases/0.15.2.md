# KonX 0.15.2 — Quick credential retention

2026-10-22. Save a username and password directly from Home Quick Connect, or use the more prominent retention checkbox in the session editor.

## Features and fixes

- **New/Edit Session → General:** find **Remember username and password** immediately above the login fields. A status label shows whether a password is already saved. Username is always part of a saved session; the checkbox controls whether a newly typed password is retained encrypted.
- **Home → Quick Connect:** enter a masked password and select **Save session and remember login** to create a saved session before connecting. This option is unchecked by default and supports SSH, Telnet, and SFTP. SFTP saves an SSH session that can be reopened with **Connect SFTP**.
- Leave Home's checkbox unchecked for a one-time connection. Quick Connect passes the typed password to SFTP as well as terminal connections.
- Preserve populated forms on save failure, prevent duplicate submissions while saving, and avoid opening a late connection after Home closes. A completed save is reused if refreshing the session list fails and the unchanged form is retried.
- Keep existing password behavior: blank edits retain saved credentials, **Remove saved password** deletes them explicitly, and an unchecked editor checkbox allows a one-time password with **Save & Connect**.

Passwords use the existing Windows-backed encryption. They are not filled back into the editor or included in public session-list data. Passwords entered in later login prompts are not automatically saved. See [Session management](../SESSION_MANAGEMENT.md).

## Upgrade

Use **Update KonX** from installed 0.6.2 through 0.15.1 or portable 0.6.0 through 0.15.1. Installed 0.6.0/0.6.1 and version 0.5.0 or earlier need a manual upgrade; see [Updating KonX](../UPDATING.md).

Windows x64 downloads: [installer](https://github.com/256kMagic/KonX/releases/download/v0.15.2/KonX-Setup-0.15.2.exe), [portable](https://github.com/256kMagic/KonX/releases/download/v0.15.2/KonX-0.15.2-portable.exe), and [checksums](https://github.com/256kMagic/KonX/releases/download/v0.15.2/SHA256SUMS.txt). ## Validation

- **800/800 automated tests passed.** The session workflow uses real Electron controls, Windows encryption, a local SSH peer, and a second application process to verify saved-login reconnection. It covers unchecked one-time credentials, save failure, duplicate clicks, a closed Home tab, and reuse after deleting a saved session.
- The editor retention checkbox is visible and clickable without scrolling at a **900 × 560** viewport. Home and editor layouts were also captured and inspected visually.
- **28/28 packaged SSH compatibility checks** and **16/16 private-key test groups** passed in the shipped Windows runtime.
- Installer and portable builds have the expected version metadata. **114 packaged source files**, **nine runtime dependencies**, and the SSH dependency patch were verified against the checkout.
- Both unpacked and portable applications passed two-launch smoke checks. Each saved a synthetic login through Home's checkbox, stored encrypted credentials, and authenticated again after restart without supplying a password to the test script. Console logging, retained layout preferences, and cleared recent history also passed their packaged checks.

Checks ran on Windows x64 with Node.js 24.13.0 and Electron 44.9.0. Executables remain unsigned; an elevated installed upgrade was not performed for this release.

## Coverage

Credential and connection checks use synthetic logins, loopback SSH peers, and isolated Windows profiles. Real network equipment and an elevated installed upgrade are outside this release's automated checks. Release validation does not change the user's installed application or profile.

The SSH runtime limits documented in [0.15.1](0.15.1.md) and the six inherited AI, Wi-Fi, and security-assessment findings listed in [0.6.3](0.6.3.md#known-issues) remain unchanged.
