# KonX 0.33.0 — Split screen and console windows

2026-10-27. Arrange open consoles with visible workspace controls and use smaller close buttons inside Home panels.

## Changes

- Click **Split screen** above the tabs or from a tab's right-click menu to arrange existing views in Workbench. Choose an open tab in each pane and resize with the divider.
- Click **Pop out** to move the active console or tool into a separate Windows window. Drag its title bar to another monitor; use **Dock back** to return it.
- Use **Single view** to return to one view without closing tabs. Splitting and popping out preserve existing connections and do not start new ones.
- Small × icons now sit inside the top-right corner of each Home section panel. **Customize Home** restores hidden sections, and existing visibility choices are retained.
- Keep saved sessions, encrypted logins, all 18 themes, layouts and terminal settings.

See the [workspace guide](../WORKSPACE_LAYOUTS.md#split-screen-shortcut), [Home guide](../USER_GUIDE.md#customize-home), and [update guide](../UPDATING.md).

## Downloads and upgrading

Windows x64: [installer](https://github.com/256kMagic/KonX/releases/download/v0.33.0/KonX-Setup-0.33.0.exe), [portable](https://github.com/256kMagic/KonX/releases/download/v0.33.0/KonX-0.33.0-portable.exe), and [checksums](https://github.com/256kMagic/KonX/releases/download/v0.33.0/SHA256SUMS.txt).

Installed 0.6.2+ and portable 0.6.0+ can use **Update KonX** in the top-right header or **Settings → Updates**. Installed 0.6.0/0.6.1 requires one manual upgrade. Save drafts, stop listeners and captures, and disconnect before restarting. Both distributions keep the existing Windows profile.
