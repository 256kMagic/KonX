# KonX 0.6.0 — local build

This build adds **Update KonX** on Home and under **Settings → Updates** for Windows x64 installed and portable copies.

One press checks the latest public GitHub release, downloads the appropriate file with progress, verifies its SHA-256 checksum, and installs/restarts when no work is active. Save documents and Knowledge notes, disconnect sessions, and stop transfers, captures, and tools first. If work remains, the update stays ready with a list of actions to finish before restart.

Installed copies keep their installation directory and mode; an all-users installation may require Windows administrator approval. Portable copies keep the same executable filename and location. Settings and the existing profile are retained. Downloads can be cancelled and retried. No GitHub token, startup polling, automatic installation on ordinary exit, prerelease update, or downgrade is used.

The published 0.5.0 app does not contain this button. Upgrade once manually to a build containing the updater; subsequent releases can be installed from inside KonX.

`npm run release:prepare` stages installer and portable files, guides, release notes, and SHA256SUMS.txt for publication. The public release must contain the complete matching bundle before it is marked latest.

See [Updating KonX](../UPDATING.md) and the [user guide](../USER_GUIDE.md). This local build has not been published to GitHub.

## Validation

- All 482 automated tests passed, including download validation, cancellation, restart guards, renderer behavior, and 15 Windows helper tests using disposable executables. Helper tests cover survival after the launching process exits, portable replacement and rollback, transient file locks, and installed-mode/directory arguments.
- Installer and portable builds completed. All 81 packaged source files match this checkout; required runtime dependencies are present.
- Isolated packaged startup/restart checks passed for unpacked and portable builds, including encrypted credential persistence/removal and Knowledge notes. The packaged updater correctly recognizes portable mode and explains why unpacked builds are unsupported.
- Updater controls were checked at a 900 × 560 viewport across eight themes. Packaged Home and Settings controls were also checked.

A complete upgrade from a future public GitHub release and a real installed NSIS upgrade have not been exercised. Installed handoff tests use a disposable installer fixture. No existing user installation was updated during validation.
