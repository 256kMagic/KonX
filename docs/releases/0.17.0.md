# KonX 0.17.0 — Serial auto baud detection

2026-10-22. Add an automatic baud-rate choice for serial text consoles, with visible progress, cancellation, and a confirmed readable sample before connecting.

## Features

- Choose **Auto detect** in a saved serial session or use `COM4@auto` in Quick Connect. Keep existing fixed-rate sessions unchanged.
- Listen by default, with an explicit **Send Enter while detecting** option for quiet consoles. Keep data bits, parity, stop bits, and flow control under the user's control.
- Try common rates, reject silent/ambiguous/garbled results, and confirm a single plausible rate with fresh output. Show the actual selected speed while retaining Auto detect in the saved session.
- Keep sampled noise out of the terminal and disable normal input and BREAK during detection. Start logon actions only after connection. Closing or disconnecting cancels the attempt and closes owned serial resources, including late opens.
- Preserve initial serial output for automatic logging and saved logon actions. If a driver does not finish closing, keep the handle tracked and block updates or exit until cleanup succeeds or can be retried.

See the [serial auto baud guide](../SERIAL_AUTO_BAUD.md) for controls, supported rates, and limitations.

## Upgrade

Use **Update KonX** from installed 0.6.2 or later or portable 0.6.0 or later. Earlier installed versions need a manual upgrade; see [Updating KonX](../UPDATING.md).

Windows x64 downloads: [installer](https://github.com/256kMagic/KonX/releases/download/v0.17.0/KonX-Setup-0.17.0.exe), [portable](https://github.com/256kMagic/KonX/releases/download/v0.17.0/KonX-0.17.0-portable.exe), and [checksums](https://github.com/256kMagic/KonX/releases/download/v0.17.0/SHA256SUMS.txt). ## Coverage

Baud detection infers a likely setting from decoded text. It is not a hardware timing measurement and cannot identify a silent port, guarantee correct interpretation of arbitrary binary data, or infer other framing/flow settings. Tests use synthetic serial bindings and isolated profiles; physical USB adapters, serial cables, and real consoles remain unverified for this release.

Executables remain unsigned. A real Windows elevation prompt and an elevated installed upgrade are not verified for this release. The limitations listed in [0.16.0](0.16.0.md#coverage), [SSH compatibility](../SSH_COMPATIBILITY.md), and [0.6.3](0.6.3.md#known-issues) remain unchanged.
