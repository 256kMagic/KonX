# KonX 0.30.0 — Five Animated Themes

2026-10-26. Five new themes bring stronger glow and distinct animated backgrounds to KonX, with coordinated terminal and editor colors.

## Changes

| Theme | Colors and motion |
| --- | --- |
| **Ion Storm** | Violet and ice blue with branching electrical arcs and traveling points of light |
| **Solar Flare** | Amber and copper with a glowing solar corona and slowly moving flares |
| **Aurora Flux** | Mint and violet with flowing aurora curtains |
| **Hyperdrive** | Ice blue and indigo with a moving starfield |
| **Ghost Circuit** | Mint and amber with pulses traveling along circuit traces |

- Select a new theme in **Settings → Appearance → Application theme**, then **Save**.
- Coordinate the interface, Notepad, and terminals set to **Follow application theme**. Explicit global and saved per-session terminal palettes retain their selected colors and opaque backgrounds.
- Pause or resume animation from the header or **Animate theme effects** in Appearance. Pausing retains the colors and decorative background; Windows reduced motion also stops animation.
- Use every theme with Classic, Docked Workbench, Incident Desk, Operations Wall, or Focus Workspace, including floating panels and native pop-outs.
- Fix theme animation in hidden or minimized native pop-outs: each window now pauses according to its own visibility and resumes when visible if motion is enabled.
- Keep all 13 earlier themes, including the five static palettes added in 0.29.0. KonX now offers 18 application themes, 11 of them animated.
- Preserve saved theme, layout, motion, terminal-palette, and clipboard preferences during upgrades. The top-right updater and terminal clipboard controls introduced in 0.28.0 remain available.

See the [theme guide and tester checklist](../THEMES.md), [Appearance guide](../USER_GUIDE.md#appearance-and-motion), and [workspace guide](../WORKSPACE_LAYOUTS.md).

## Downloads and upgrading

Windows x64: [installer](https://github.com/256kMagic/KonX/releases/download/v0.30.0/KonX-Setup-0.30.0.exe), [portable](https://github.com/256kMagic/KonX/releases/download/v0.30.0/KonX-0.30.0-portable.exe), and [checksums](https://github.com/256kMagic/KonX/releases/download/v0.30.0/SHA256SUMS.txt).

Installed 0.6.2+ and portable 0.6.0+ can use **Update KonX**. The shortcut is at the top right in 0.28.0+, or on Home in older releases; **Settings → Updates** also remains available. Installed 0.6.0/0.6.1 requires one manual upgrade. Save drafts, stop listeners and captures, and disconnect before restarting. Both distributions keep the existing Windows profile. See the [update guide](../UPDATING.md).
