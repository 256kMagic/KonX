# KonX 0.10.0 — Incident workspaces

Keep captures, selected terminal output, tool results, imported syslog, and notes together in a local incident with a timeline and portable reports.

## Features

- Named incident library with append-only evidence, notes, source provenance, and explicit removal.
- **Add to incident** on diagnostic tools and Packet Capture, plus selected terminal text from the tab menu. Choose a destination and explicitly add the pending snapshot.
- Independent local copies with SHA-256 integrity checks and verified reopening of retained captures.
- Syslog file import and source-linked timelines that preserve unknown years, timezones, and timestamps.
- Escaped HTML and structured JSON reports with bounded text, evidence metadata, and coverage notes.
- Summary-only AI context and unfinished-work guards for tab closing and updater restart.
- Correct listener-port reporting for operating-system-assigned SSH forwarding ports; the forwarding fixture now uses that owned listener instead of a random port number.

See the [incident guide](../INCIDENT_WORKSPACES.md), [user guide](../USER_GUIDE.md), and [phased roadmap](../ROADMAP.md).

## Upgrade

Use **Update KonX** from installed 0.6.2 or later or portable 0.6.0 or later. Older installed copies need a manual upgrade; see [Updating KonX](../UPDATING.md).

Windows x64 downloads: [installer](https://github.com/256kMagic/KonX/releases/download/v0.10.0/KonX-Setup-0.10.0.exe), [portable](https://github.com/256kMagic/KonX/releases/download/v0.10.0/KonX-0.10.0-portable.exe), and [checksums](https://github.com/256kMagic/KonX/releases/download/v0.10.0/SHA256SUMS.txt). Executables remain unsigned.

- Real Electron incident checks passed: evidence copy and verified reopening, HTML/JSON export, unknown timestamps, explicit pending-evidence selection, updater/close guards, and narrow/wide layouts.

## Coverage

Incident evidence stays in ordinary local profile files. HTML/JSON reports embed bounded text and metadata, not binary capture contents. Syslog import does not start a listener. Unknown source times remain unknown. Drafts and pending items are not saved until explicitly added, and forced shutdown can discard them.

The six inherited AI, Wi-Fi, and security-assessment findings listed in [0.6.3](0.6.3.md#known-issues) remain unchanged.
