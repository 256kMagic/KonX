# KonX 0.22.0 — Guided Change Validation

2026-10-23. Keep maintenance plans, before/after evidence, and explicit review decisions together.

## Changes

- Create a saved validation with scope, expected outcome, manual rollback plan, and review checklist. Work through Plan, Baseline, Manual maintenance, After evidence, and Review.
- Select separate saved snapshots and compare their existing observations. Open Device Inspector, Runbooks, or Capture Comparison explicitly; no phase runs commands or applies configuration.
- Preview and retain reviewed Runbook/Capture Comparison results, including their source references and uncertainty. Missing observations remain unknown.
- Record manual maintenance with an explicit acknowledgment. Review each checklist item as Pass, Fail, or Unknown with rationale and retained evidence references; KonX does not infer a service-health verdict.
- Export the full saved report as JSON/HTML or copy it into an incident after review. Revision checks protect against stale exports and concurrent edits.
- Preserve drafts on cancelled/failed actions, invalidate assessments when their inputs change, and retain file ownership through shutdown and cleanup retries.

Read [Guided Change Validation](../CHANGE_VALIDATION.md), [Device Snapshots](../DEVICE_SNAPSHOTS.md), [Runbooks](../RUNBOOKS.md), and [Updating KonX](../UPDATING.md).

## Coverage

Checks use isolated profiles, synthetic device reports, offline captures, and owned loopback peers. Real maintenance, production-device collection, live cloud services, and an elevated installed upgrade remain unverified. Executables remain unsigned. Decisions are the user's recorded assessment; changed observations do not establish failure and unchanged observations do not establish health. Reports can retain sensitive notes and command output, so review them before sharing.

The intermittent Windows incident-manifest rename error observed during 0.21.0 development remains unexplained; subsequent focused probes passed. This release does not claim a fix for that error.
