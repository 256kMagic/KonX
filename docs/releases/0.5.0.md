# KonX 0.5.0

This Windows x64 release adds six animated application themes and includes the AI and knowledge workspace, Security Suite, Wi-Fi diagnostics, and Mist/Marvis monitoring introduced since the previous public release.

- **Six themes:** Arc Reactor, Chroma RGB, Matrix Mainframe, Synthwave Grid, Hologram Prism, and Plasma Forge. Each combines its own palette, glow, and motion.
- **Compact workspace:** a compact top header keeps the workspace available for tools. Animated artwork sits behind terminal and editor output, with quieter surfaces for tables, forms, and explanations.
- **Motion controls:** use **Pause effects** in the top header or **Animate theme effects** under **Settings → Appearance**. The preference persists across launches. KonX respects Windows' reduced-motion preference and disables the header motion button while it is active.
- **Coordinated output:** application themes automatically coordinate Notepad's palette and background. The new **Follow application theme** terminal scheme coordinates terminal colors and backgrounds, and is the default for new profiles.
- **Classic choices retained:** Dark and Light application themes and all existing terminal color schemes remain available. Upgrading preserves explicit global and per-session terminal palettes, including their original colors and opaque backgrounds.

## Included since the previous public release

- **Security Suite:** local Windows posture, remote Windows service exposure, TLS/SSH, web-header, common-service, device-configuration, and saved-capture assessments. Findings include evidence, recommendations, local baselines, and JSON/HTML reports. The local Windows checks read posture settings; they do not perform an antivirus malware scan. [Security Suite guide](../SECURITY_SUITE.md).
- **Wi-Fi and Mist/Marvis:** Windows adapter and cached BSSID diagnostics, signal/channel views, encrypted Mist-token storage, authorized organization/site selection, AP/client monitoring, and direct Marvis troubleshooting. Mist operations cover monitoring and troubleshooting. [Wi-Fi and Mist guide](../WIRELESS_MIST_GUIDE.md).
- **AI & Knowledge:** separate encrypted connections for OpenAI, Claude, Gemini, Nyquest, and a custom OpenAI-compatible endpoint; 46 bundled reference articles and editable notes; and an offline background SQLite index with persistent TF-IDF cosine vectors. **Explain with AI** prepares bounded tool results for review and opt-in sharing. Library search needs no API key, and AI suggestions do not execute tools. [AI and knowledge guide](../AI_KNOWLEDGE_GUIDE.md).
- **Fixes and diagnostics:** SFTP cancellation and original-file preservation, editor recovery, connection cleanup, packet/capture validation, and local JavaScript error logs. See the [changelog](../../CHANGELOG.md) for the full history.

## Try the themes

1. Open **Settings → Appearance**.
2. Choose an **Application theme**. To coordinate terminal colors and backgrounds on an existing profile, also set **Terminal color scheme → Follow application theme**. Choose **Save**.
3. Open a terminal or Notepad to see its output background, then inspect a tool tab to compare the quieter data surfaces.
4. Use **Pause effects** and **Resume effects** in the top header to compare static and animated appearances.
5. Return to Dark or Light whenever you want the classic appearance. Choose a separate **Terminal color scheme** if desired. A saved session's explicit scheme in **Terminal & Log** continues to override the global selection.
