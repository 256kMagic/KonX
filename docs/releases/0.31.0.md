# KonX 0.31.0 — Customize Home

2026-10-27. Hide the Home sections you do not need and bring them back when wanted. KonX keeps your choices between launches.

## Changes

- Close **Introduction**, **Quick connect**, **Recent sessions**, **Sessions**, **Network tools**, or **Keyboard** using the section's × button.
- Open **Customize Home**, choose visible sections or use **Restore all**, then **Save**. The control stays available when every section is hidden.
- Retain your choices when reopening Home, changing workspace layouts, or restarting KonX. New profiles and upgrades from 0.30.0 or earlier initially show all sections.
- Keep saved sessions, recent history, active connections, and tools intact. Closing a Home section only changes its visibility on the landing page.
- Hiding Quick connect clears its unsaved password and stops a pending **Save & connect** action from opening a connection afterward. If the save finishes, the saved login remains available in Sessions.
- Keep all 18 application themes, terminal-palette overrides, header updater, and terminal clipboard controls.

See [Customize Home](../USER_GUIDE.md#customize-home), the [workspace guide](../WORKSPACE_LAYOUTS.md#home-sections), and the [update guide](../UPDATING.md).

## Downloads and upgrading

Windows x64: [installer](https://github.com/256kMagic/KonX/releases/download/v0.31.0/KonX-Setup-0.31.0.exe), [portable](https://github.com/256kMagic/KonX/releases/download/v0.31.0/KonX-0.31.0-portable.exe), and [checksums](https://github.com/256kMagic/KonX/releases/download/v0.31.0/SHA256SUMS.txt).

Installed 0.6.2+ and portable 0.6.0+ can use **Update KonX**. The shortcut is at the top right in 0.28.0+, or on Home in older releases; **Settings → Updates** also remains available. Installed 0.6.0/0.6.1 requires one manual upgrade. Save drafts, stop listeners and captures, and disconnect before restarting. Both distributions keep the existing Windows profile. See the [update guide](../UPDATING.md).
