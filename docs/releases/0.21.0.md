# KonX 0.21.0 — Live Events

2026-10-23. Receive syslog and SNMP trap observations inside KonX.

## Changes

- Open **Network Tools → Live Events**, choose protocol, local bind address and UDP port, then start explicitly. Default addresses receive loopback traffic only; a network-facing address must be selected for remote devices.
- Read RFC5424 and common RFC3164 syslog fields, SNMPv1/v2c trap OIDs and typed values. Missing source times stay unknown; community strings and raw SNMP packets are excluded. SNMPv3 and informs are unsupported and receive no response.
- Search and filter bounded history, select event details, prepare an exactly matched saved session, or activate an existing connected terminal. Source address matches do not authenticate a device.
- Review JSON/text exports and add selected evidence to an incident. AI receives counts and coverage, not event contents.
- Stop individual receivers, clear history, reload/remove stopped histories, and retry failed socket cleanup. Updating and shutdown wait for owned listeners; nothing listens automatically after restart.
- Protect Saved Site Workspaces from exports directed through Windows folder aliases into the managed workspace library.

Read [Live Events](../EVENTS.md), [Incident Workspaces](../INCIDENT_WORKSPACES.md), and [Updating KonX](../UPDATING.md).

## Downloads and upgrading

Windows x64: [installer](https://github.com/256kMagic/KonX/releases/download/v0.21.0/KonX-Setup-0.21.0.exe), [portable](https://github.com/256kMagic/KonX/releases/download/v0.21.0/KonX-0.21.0-portable.exe), and [checksums](https://github.com/256kMagic/KonX/releases/download/v0.21.0/SHA256SUMS.txt).

Installed 0.6.2+ and portable 0.6.0+ can use **Update KonX**. Installed 0.6.0/0.6.1 requires one manual upgrade. Save work, stop listeners, and disconnect before restarting; the existing profile remains in use.

- Full automated suite: **959/959 passed**, including real IPv4/IPv6 UDP parsing and reception, malformed SNMP bounds, no-acknowledgment behavior, stop/retry ownership, multi-view history reset, and main updater/shutdown integration.
- All **136 packaged source files** and 9 runtime dependencies matched the tested checkout. Packaged SSH checks passed 28 negotiation and 16 key cases; synthetic serial checks passed 27 cases.
- Unpacked and portable builds received synthetic loopback syslog, displayed parsed fields, selected bounded evidence, kept AI context to summaries, and stopped/cleared their receivers. Restart preserved existing test settings and restored no listener or event history.
- Real Electron event workflows passed with production styles; compact and larger desktop layouts were inspected. Windows junction tests preserved managed workspace records and prevented alias retargeting from redirecting exports; exact 1 MiB workspace save/reopen passed.
- Installer, portable, and unpacked executable versions matched 0.21.0.

## Coverage

Receivers are tested with synthetic loopback datagrams, isolated profiles, and injected cleanup failures. Real device forwarding, host firewall traversal, sustained production traffic, and an elevated installed upgrade remain unverified. Executables remain unsigned. UDP delivery is not guaranteed; drops before the socket callback cannot be counted. No TLS syslog, SNMP polling, MIB name lookup, SNMPv3, or inform acknowledgement is implemented.

One development Electron fixture encountered an intermittent Windows EPERM replacing an incident manifest. Its immediate rerun and a separate 20-case instrumented create/add probe passed; the probe found no overlapping store operations or open owned handles at rename. The cause remains unresolved, and this release does not claim to fix it. A failed save should remain visible for retry.
