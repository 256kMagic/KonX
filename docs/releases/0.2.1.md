# KonX 0.2.1 test build

This build combines the 0.2.0 SIP ladders, readable HTTP traffic, reconstructed streams, capture exports, and interface improvements with the subsequent safety and correctness fixes.

- Interrupted SFTP downloads preserve existing local files; cancelled and closed sessions clean up pending transfers and connections.
- Editor saves and reloads protect original files and intervening edits; UTF-16 search handles both byte orders.
- SSH jump failures, logging errors, and supported OpenSSH import syntax are handled correctly.
- Malformed capture files and filter typos fail safely; packet decoding stays within payload boundaries.
- HTTP framing, SIP validation and call timing, DNS matching, and zero-valued TCP timing are corrected.
- Capture-save errors are shown, saved counts match the exported snapshot, and packet evidence remains visible during live capture.
- Network-tool startup/cancellation and large port scans preserve results and avoid unnecessary memory allocation.

Validation: **279/279 tests passed**. The packaged Windows app reports version 0.2.1 and passed an isolated 23-packet SIP check covering three calls, 19 messages, SDP, split TCP reconstruction, packet navigation, and JSON/PCAPNG round trips retaining the selected call's 14 original frames. All 53 source files in the package match the reviewed source.

The installer and portable executable are Windows x64 test builds. They remain unsigned. This build step does not publish a new GitHub Release. Close KonX before upgrading; the installer retains the existing installation mode and application profile. See the [user guide](../USER_GUIDE.md) and [changelog](../../CHANGELOG.md) for details.
