# KonX 0.20.0 — Visual Topology

2026-10-23. Explore device observations as a clickable map.

## Changes

- Open topology from Device Inspector, a saved snapshot, a JSON report, or the synthetic demo. Opening a map starts no collection or device connection.
- Select nodes and links to see recorded interfaces, neighbor protocols, collection times, and original source-command lines. Return to Device Inspector or activate the original connected terminal explicitly.
- Trace candidate IPv4/MAC paths from observed ARP and forwarding entries. Ambiguous identities, stale evidence, incomplete commands, and bounded omissions remain visible.
- Arrange nodes with pointer or keyboard, pan, zoom, and fit the map. Map positions are schematic; links do not prove current physical connectivity.
- Export JSON with canonical source observations and reopen it to rebuild the map. Add bounded graph evidence to an incident; AI previews receive summary counts and coverage.

Read [Visual Topology](../TOPOLOGY.md), [Device Inspector](../DEVICE_INSPECTOR.md), [Device Snapshots](../DEVICE_SNAPSHOTS.md), and [Updating KonX](../UPDATING.md).

Windows x64: [installer](https://github.com/256kMagic/KonX/releases/download/v0.20.0/KonX-Setup-0.20.0.exe), [portable](https://github.com/256kMagic/KonX/releases/download/v0.20.0/KonX-0.20.0-portable.exe), and [checksums](https://github.com/256kMagic/KonX/releases/download/v0.20.0/SHA256SUMS.txt).

Installed 0.6.2+ and portable 0.6.0+ can use **Update KonX**. Installed 0.6.0/0.6.1 requires one manual upgrade. Save work and disconnect before restarting; the existing profile remains in use.

## Coverage

Validation uses synthetic reports, isolated profiles, and owned loopback peers. Real switch collection, physical topology accuracy, real mixed-monitor operation, and an elevated installed upgrade remain unverified in this release. Executables remain unsigned. Topology is an interpretation of recorded observations, with bounded graph size and explicit uncertainty; exports can retain sensitive command output and should be reviewed before sharing.
