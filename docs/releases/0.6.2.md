# KonX 0.6.2 — October 21, 2026

KonX 0.6.2 fixes two issues that prevented the installed **Update KonX** button from working. It includes updated release notes and user guides covering installed and portable upgrades, settings preservation, and recovery.

**Installed 0.6.0 and 0.6.1 users must run the 0.6.2 installer manually once.** Their existing buttons cannot install this fix. Portable 0.6.0 and 0.6.1 users can choose **Update KonX** on Home or under **Settings → Updates**.

## Fixes

- Installed application detection now checks the physical application archive. Electron exposes `app.asar` as a virtual directory to its normal filesystem API, which previously made a valid installation appear unsupported.
- The update helper reads the install location and uninstall metadata from electron-builder's separate Windows registry keys. It validates the application identity, installation folder, uninstaller command, and per-user/all-users mode together before installation.
- Regression coverage exercises a real ASAR under normal Electron, the installer's paired registry layout, and invalid or ambiguous installation records.

From 0.6.2, an installed update preserves the installation folder and mode. An all-users update can require Windows administrator approval. Portable updates retain the original executable filename and location. Both distributions continue using the existing Windows profile. Progress, checksum verification, download cancellation, and checks for work that must be saved before restart remain available.

## How to upgrade

| Current copy | Action |
| --- | --- |
| Installed 0.6.0 or 0.6.1 | Save your work, close KonX, and run `KonX-Setup-0.6.2.exe` using the existing installation folder and mode. |
| Portable 0.6.0 or 0.6.1 | Choose **Update KonX** and finish any work listed before restart. |
| Version 0.5.0 or earlier | Close KonX and run the installer, or replace the portable executable manually. |

Do not uninstall the existing copy or delete its profile to upgrade. Settings, saved sessions, encrypted credentials, and the Knowledge library remain in the existing profile. Save capture evidence and local or remote documents before restarting; active terminal connections and capture buffers are not restored.

The Windows x64 release includes [KonX-Setup-0.6.2.exe](https://github.com/256kMagic/KonX/releases/download/v0.6.2/KonX-Setup-0.6.2.exe), [KonX-0.6.2-portable.exe](https://github.com/256kMagic/KonX/releases/download/v0.6.2/KonX-0.6.2-portable.exe), downloadable guides, these release notes, and [SHA256SUMS.txt](https://github.com/256kMagic/KonX/releases/download/v0.6.2/SHA256SUMS.txt). For a manual download, compare `Get-FileHash .\KonX-Setup-0.6.2.exe -Algorithm SHA256` with the manifest. Checksums establish consistency with the GitHub release; the executables remain unsigned.

See [Updating KonX](../UPDATING.md) and the [user guide](../USER_GUIDE.md) for step-by-step instructions, cancellation, and recovery.

## Existing features

The six animated themes—Arc Reactor, Chroma RGB, Matrix Mainframe, Synthwave Grid, Hologram Prism, and Plasma Forge—remain available alongside Dark and Light. This release retains packet reassembly, readable HTTP, SIP call lists and signaling ladders, SDP inspection and call export, SSH/SFTP, Notepad, Security Suite, Wi-Fi/Mist tools, and AI & Knowledge.

## Known issues

The following six findings from the 0.5.0 review remain **unfixed** in 0.6.2:

1. AI reference chunk boundaries can remove a credential's identifying label before redaction. Do not put sensitive credentials in custom Knowledge notes or rely on redaction to make them safe for AI requests.
2. Knowledge retrieval can select a matching chunk but omit its relevant passage when shortening the excerpt sent to AI.
3. Mixed WPA/WPA2 advertisements can lose evidence of weak WPA/TKIP alternatives in the Wi-Fi report.
4. Wi-Fi reports can omit a weak group cipher when the pairwise cipher is stronger.
5. HSTS checks can misclassify quoted `max-age` values and duplicate directives.
6. Unapplied Cisco macro bodies can be interpreted as active settings by the offline configuration assessment.

Verify affected assessments against the original evidence. AI and Mist tests use simulated provider responses; they do not establish live-account interoperability.

## Validation

The 0.6.2 source passed all **485 automated tests**, including 18 Windows update-install tests. The regressions cover Electron's real ASAR filesystem behavior, the paired installation registry keys, and 17 registration cases, alongside existing download, cancellation, restart, and portable rollback checks.

The Windows x64 installer and portable executable built successfully. All 81 packaged source files match the release source, including the updater fixes; required runtime dependencies and x64 native bindings are present. Isolated unpacked and portable 0.6.2 startup/restart checks passed, including synthetic encrypted credential persistence/removal and custom Knowledge note persistence/removal. Packaged Home and Settings updater controls report the correct version and portable support, while the unpacked build remains unsupported. These checks used disposable profiles and did not modify the user's running installation.

On October 21, corrected source download/handoff components completed a real all-users NSIS upgrade from installed 0.6.0 to the published 0.6.1 installer. KonX exited normally, the user approved Windows elevation, and it restarted as 0.6.1 in the same folder and installation mode. Settings were byte-for-byte unchanged, the saved theme and toolbar were present, and the Knowledge database integrity check passed. The original installed 0.6.0 button failed; this was a corrected-component test, not a successful test of that released button or a complete update from a packaged 0.6.2 button.

No saved sessions, credentials, custom Knowledge notes, or Notepad recovery files were present in that live profile, so their retention was not exercised by the live test. The published portable 0.6.0 → 0.6.1 update and restart were also verified with existing settings unchanged. These results do not establish a complete 0.6.2 → future-release update.
