# KonX 0.18.1 — Tester support and reliability

2026-10-23. This maintenance release starts the next site-workflow roadmap.

## Changes

- Add **Report a problem** on Home and Settings → Support. Preview/edit a local diagnostic report, optionally include bounded JavaScript error logs, and save it for manual sharing. No automatic uploads or profile-content collection.
- Preserve incident drafts on failed saves and show explicit success/failure. Avoid a post-commit manifest reread that could falsely report a failed save and encourage duplicate retries.
- Recover owned pop-out windows into an available display work area after display changes while preserving native minimized/maximized state.
- Redact recognized credentials before AI reference chunking and answer truncation, and select reference excerpts around matching query terms.
- Preserve mixed WPA/RSN advertisements and group ciphers in Wi-Fi assessments, including weaker or unknown advertised options.
- Interpret quoted HSTS values, duplicate directives, and repeated headers correctly. Exclude stored Cisco macro bodies from active configuration findings.

Read [Tester support](../TESTER_SUPPORT.md), [Workspace controls](../WORKSPACE_LAYOUTS.md), and [Updating KonX](../UPDATING.md).

## Downloads and upgrading

Windows x64: [installer](https://github.com/256kMagic/KonX/releases/download/v0.18.1/KonX-Setup-0.18.1.exe), [portable](https://github.com/256kMagic/KonX/releases/download/v0.18.1/KonX-0.18.1-portable.exe), and [checksums](https://github.com/256kMagic/KonX/releases/download/v0.18.1/SHA256SUMS.txt).

Installed 0.6.2+ and portable 0.6.0+ can use **Update KonX**. Installed 0.6.0/0.6.1 requires one manual upgrade. Save work before restarting; existing settings and saved credentials remain in the current profile.
