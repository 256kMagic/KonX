# KonX 0.32.0 — Save on-demand sessions

2026-10-27. Keep a connection you opened on demand in Saved Sessions without re-entering its connection settings or interrupting your work.

## Changes

- Choose **Save session** in an open terminal or SFTP tab, or from its application tab menu.
- Review the filled-in connection settings, choose a name and folder, and optionally save login credentials using the existing encrypted local store.
- Keep the live connection running while saving. Use **Edit saved session** afterward to update the same saved record.
- Share the saved reference between a terminal and SFTP opened from it. Cloned on-demand connections can be saved separately. Saved connections can be included in Site workspaces.
- Prefill a known authenticated username and available Quick Connect password. Login-prompt passwords and challenge answers are not recovered; enter a reusable password in the save form if needed.
- Keep save requests associated with the created record through repeated clicks, closed dialogs and sidebar refresh failures. A failed write leaves the form available for retry.
- Retain Home visibility choices, all 18 themes, workspace layouts, terminal palettes, clipboard controls and existing sessions.

See [Save an on-demand connection](../SESSION_MANAGEMENT.md#save-an-on-demand-connection), the [user guide](../USER_GUIDE.md), and the [update guide](../UPDATING.md).

## Downloads and upgrading

Windows x64: [installer](https://github.com/256kMagic/KonX/releases/download/v0.32.0/KonX-Setup-0.32.0.exe), [portable](https://github.com/256kMagic/KonX/releases/download/v0.32.0/KonX-0.32.0-portable.exe), and [checksums](https://github.com/256kMagic/KonX/releases/download/v0.32.0/SHA256SUMS.txt).

Installed 0.6.2+ and portable 0.6.0+ can use **Update KonX** in the top-right header or **Settings → Updates**. Installed 0.6.0/0.6.1 requires one manual upgrade. Save drafts, stop listeners and captures, and disconnect before restarting. Both distributions keep the existing Windows profile.
