# KonX 0.2.0

KonX 0.2.0 adds readable reconstructed traffic and SIP call investigation, and fixes the session-dialog, packet-following, tab-overflow, button-bar, and Quick Connect interface issues.

## Reassemble and read captured traffic

**Follow TCP stream** now reconstructs each direction in sequence order, handles out-of-order packets and retransmissions, and marks missing bytes or conflicting overlaps. UDP views preserve individual datagrams. Text and hex views include links back to the source packets.

For plaintext HTTP/1, the readable view pairs requests and responses, displays headers and text, formats JSON, removes chunk framing, and decodes supported gzip/deflate bodies. **Save body** exports a complete decoded body to a location you choose. Incomplete or ambiguous bodies remain visible for inspection without being offered as complete recovered files. Captured HTML is displayed as text.

## Investigate SIP calls

Open a capture in **Packet Capture**, then choose **SIP Calls**. The call list examines a snapshot of the retained capture, including packets hidden by the display filter.

- Search calls by Call-ID, parties, outcome, or method.
- Follow messages across endpoint lanes and click an arrow to inspect the message, its SDP, and its source packets.
- Inspect observed setup time, call duration, retransmissions, authentication challenges, and separate tagged dialogs for forked calls.
- Read advertised SDP addresses, ports, codecs, format parameters, media direction, and explicit RTCP details.
- Choose **Export call PCAPNG** for original signaling packets or **Export JSON report** for the analyzed call, messages, SDP, packet references, and warnings.

The view stays tied to its opening snapshot. Close and reopen it to include packets captured afterward. A source-packet link returns to that packet and pauses Auto-scroll; it clears the display filter only when the filter hides the packet.

PCAPNG exports retain whole frames, including observed retransmissions. If several SIP messages share a TCP frame, that exported frame can include another call's message. RTP media is not included in the call export.

## Interface fixes

- **Stable session dialogs:** changing a panel no longer shifts its navigation tabs vertically. Dialog actions remain reachable in smaller windows.
- **Accurate Auto-scroll state:** scrolling upward pauses following and unchecks the control. Check it again to resume; reaching the bottom alone does not resume a manual pause.
- **Reachable application tabs:** scroll arrows, mouse-wheel scrolling, and **Show all tabs** expose tabs beyond the window edge. Background status updates preserve the chosen scroll position.
- **Clear button-bar control:** a dedicated icon replaces the three dots, with a Show/Hide tooltip and pressed state.
- **Consistent Quick Connect styling:** its protocol selector and address field match the other form controls, and toolbar controls adapt to narrower windows.
- **Correct development version:** the app reports the KonX package version instead of the Electron runtime version.

## Limits and upgrading

These tools analyze captured evidence. Gaps, truncation, conflicting bytes, unknown values, and resource limits remain visible. SIP over TLS, HTTP/2 decoding, RTP audio reconstruction, SRTP decryption, and audio playback are not included. SDP describes what was advertised in a message; it does not prove media connectivity or a successful codec negotiation.

Windows x64 remains the release target. Save documents and close KonX before installing the update. The installer and portable executable use the existing Windows profile; this release does not add a profile migration or automatic updater. Executables remain unsigned.

## Release validation

- `npm test`: 226/226 tests passed on Windows, including real Electron checks for session panels, tab overflow, the SIP ladder, SDP, source-packet navigation, and both export actions.
- `npm run dist -- --publish never`: built the Windows x64 installer and portable executable.
- Packaged application smoke test: verified version 0.2.0, loaded the 23-packet sample from the packaged application, found three calls and 19 SIP messages, checked SDP, and round-tripped the JSON report and 14 original signaling packets for the selected call. The packaged SIP view was visually inspected.
- The sample is synthetic. These checks do not establish interoperability with every PBX, SBC, phone, capture adapter, or live network.
