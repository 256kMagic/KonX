# KonX 0.12.0 — Troubleshooting runbooks

Run reviewed troubleshooting procedures with explicit targets, retained observations, and reusable local definitions.

## Features

- Built-in gateway, slow application, and phone-with-no-audio procedures.
- Typed host, TCP port, and connected-device inputs with visible steps before collection starts.
- Sequential DNS, ICMP, TCP, fixed Cisco inventory, manual checklist, and manual SIP/RTP review steps.
- Pass/fail/unknown evidence, deadlines, cancellation, result export, and incident attachment.
- Local custom procedure library with JSON review, import/export, atomic save, explicit removal, and unsaved-work guards.
- Application shutdown waits for owned runbook probes and local file cleanup.
- Known pending capture/runbook cleanup failures block updater installation until cleanup can be retried.

See the [runbook guide](../RUNBOOKS.md), [user guide](../USER_GUIDE.md), and [phased roadmap](../ROADMAP.md).

## Upgrade

Use **Update KonX** from installed 0.6.2 or later or portable 0.6.0 or later. Older installed copies need a manual upgrade; see [Updating KonX](../UPDATING.md).

Windows x64 downloads: [installer](https://github.com/256kMagic/KonX/releases/download/v0.12.0/KonX-Setup-0.12.0.exe), [portable](https://github.com/256kMagic/KonX/releases/download/v0.12.0/KonX-0.12.0-portable.exe), and [checksums](https://github.com/256kMagic/KonX/releases/download/v0.12.0/SHA256SUMS.txt). Executables remain unsigned.

## Coverage

Checks originate from this KonX computer and do not establish the affected client's path or a unique root cause. A completed procedure can contain failures and unknowns. Manual steps remain unknown when a capture viewer opens. Definitions cannot execute scripts or arbitrary device commands.

Definitions are bounded to 64 KiB, 24 steps, 12 inputs, two device steps, and five minutes overall. DNS uses a dedicated resolver; address probes use the first resolved address. Automated verification uses local DNS/TCP peers, Windows ping, synthetic captures, and device-collection fixtures. Real switches and live telephone calls remain unverified.

The six inherited AI, Wi-Fi, and security-assessment findings listed in [0.6.3](0.6.3.md#known-issues) remain unchanged.
