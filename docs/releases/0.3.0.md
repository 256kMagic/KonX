# KonX 0.3.0 test build

This Windows x64 test build adds the Security Suite, local Wi-Fi diagnostics, direct Juniper Mist monitoring, and structured Marvis troubleshooting to the fixes in [0.2.1](0.2.1.md).

- **Security Suite:** eight assessments covering this PC's Windows security posture, remote Windows service exposure, TLS certificates, SSH negotiation, web headers, common TCP services, supported device configurations, and saved captures. Findings include evidence, recommendations, confidence, local baselines, and JSON/HTML exports.
- **Wi-Fi Tools:** Windows WLAN adapters and connection details, cached nearby SSIDs/BSSIDs, signal strength, advertised security, and primary-channel observations, with JSON export.
- **Mist & Marvis:** API-token storage encrypted for the current Windows account, twelve Mist cloud regions, authorized organization/site selection, AP and wireless-client snapshots, and direct device/site troubleshooting through Marvis.
- **JavaScript diagnostics:** startup errors, uncaught main-process errors, and unhandled-rejection warnings are saved locally so details can survive a dismissed error dialog.

## Try the new tools

1. Open **Security Suite** from Home, the sidebar, or the Network Tools menu. Choose **Windows — this PC** and click **Run assessment** for 14 local checks. Restricted or unavailable checks remain **Unknown**. To review another Windows host, choose **Windows — remote service exposure** and enter its hostname or IP. Select a finding for its evidence; use **Set baseline**, **Compare baseline**, or the export buttons to retain results. **Cancel assessment** or closing the tab stops the active job.
2. Open **Wi-Fi Tools** and click **Refresh Wi-Fi snapshot**. Review adapters, nearby networks, channels, and observations. Windows location permissions, adapter support, radio state, and the WLAN AutoConfig service can affect the available evidence. The tool reads the existing Windows WLAN cache; observations may predate collection. Channel counts are not airtime or interference measurements.
3. Open **Mist & Marvis**, select the organization's cloud, enter its API token, and click **Save token**, then **Test connection**. Choose an organization/site to retrieve **Access points** or **Wireless clients**. For Marvis, select the organization and a site or device MAC, choose a troubleshooting category and time range, then click **Ask Marvis Troubleshoot**. A suitable token scope and organization-level Marvis subscription are required. Use **Export JSON** to retain the returned response and request scope.

Opening these tabs does not start assessments or cloud requests. Mist operations are limited to monitoring and troubleshooting; this interface uses structured inputs rather than free-form conversational chat. The local Windows assessment reads security settings without changing them or running an antivirus malware scan. Remote Windows checks report service reachability from this PC; detailed Windows posture checks run locally on the host being assessed.

## Installation and local data

Close KonX before upgrading. The installer retains the existing installation mode and application profile; an all-users installation in Program Files can require Windows administrator approval. The installer and portable executable are unsigned Windows x64 test builds. Building and installing this version does not publish a GitHub Release.

Baselines, Wi-Fi snapshots, and diagnostic logs stay local unless you choose to export or share them. Mist sends the selected monitoring or troubleshooting request directly to the chosen Mist cloud; it does not upload local Wi-Fi snapshots or KonX documents. The encrypted Mist token is stored separately in the profile's `mist.json`, is not returned to the page, and can be removed with **Forget token**.

JavaScript error details are saved in `diagnostics/javascript-errors.log` under the active KonX profile, normally `%APPDATA%\KonX`. The previous log is `javascript-errors.previous.log`. Reports and diagnostics can contain target names and operational details; review them before sharing.

The 0.3.0 source regression suite passed **384 tests**. All 67 application source files were verified against the packaged archive. The unpacked application, portable executable, and installed Program Files application passed isolated checks for the three new tools, offline configuration assessments, redacted exports, and encrypted synthetic-token persistence and removal across a restart. The installed application archive matched the tested build. The packaged WLAN library loaded and bound successfully without querying nearby networks. Mist requests and Marvis responses were tested with fixtures; a live Mist account and real API key have not been used for validation. The usable Wi-Fi survey data depends on the target PC and its Windows permissions.
