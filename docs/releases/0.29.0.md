# KonX 0.29.0 — Five New Application Themes

2026-10-26. Five static themes bring coordinated dark and light palettes to the KonX workspace.

## Changes

| Theme | Appearance |
| --- | --- |
| **Obsidian Gold** | Charcoal surfaces with warm gold accents |
| **Arctic Glass** | Cool light surfaces and cobalt accents, including a light terminal |
| **Deep Ocean** | Dark petrol surfaces with seafoam accents |
| **Sandstone** | Warm paper surfaces and clay accents, including a light terminal |
| **Crimson Circuit** | Plum-charcoal surfaces with rose-red accents |

- Select a new theme in **Settings → Appearance → Application theme**, then **Save**.
- Coordinate the interface, Notepad, and terminals set to **Follow application theme**. Explicit global and saved per-session terminal palettes retain their selected colors.
- Use any theme with Classic, Docked Workbench, Incident Desk, Operations Wall, or Focus Workspace, including floating panels and native pop-outs.
- Match Events and Site Workspace error/selection colors to the active theme and improve packet warning-row contrast in the new light themes.
- Keep existing appearance preferences during upgrades. The five new themes are static; the six existing animated themes retain their saved pause/resume and reduced-motion behavior.
- Retain the top-right **Update KonX** button and the right-click paste and automatic-copy options introduced in 0.28.0.

See the [theme guide and tester checklist](../THEMES.md), [Appearance guide](../USER_GUIDE.md#appearance-and-motion), and [workspace guide](../WORKSPACE_LAYOUTS.md).

## Downloads and upgrading

Windows x64: [installer](https://github.com/256kMagic/KonX/releases/download/v0.29.0/KonX-Setup-0.29.0.exe), [portable](https://github.com/256kMagic/KonX/releases/download/v0.29.0/KonX-0.29.0-portable.exe), and [checksums](https://github.com/256kMagic/KonX/releases/download/v0.29.0/SHA256SUMS.txt).

Installed 0.6.2+ and portable 0.6.0+ can use **Update KonX**. The shortcut is at the top right in 0.28.0+, or on Home in older releases; **Settings → Updates** also remains available. Installed 0.6.0/0.6.1 requires one manual upgrade. Save drafts, stop listeners and captures, and disconnect before restarting. Both distributions keep the existing Windows profile. See the [update guide](../UPDATING.md).
